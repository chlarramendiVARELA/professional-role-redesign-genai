# GitHub repository setup

Use the following values when creating the public repository.

## Repository details

- **Repository name:** `professional-role-redesign-genai`
- **Description:** `A 4V framework for analysing automation, augmentation, human value and expertise-building in AI-enabled professional work.`
- **Visibility:** Public
- **Initialise repository with a README:** No — this package already contains one.
- **Add .gitignore:** None
- **Choose a licence:** None

## Suggested topics

`generative-ai`, `future-of-work`, `job-redesign`, `human-ai-collaboration`, `expertise`, `reskilling`, `project-management`, `responsible-ai`

## Upload

After creating the empty repository:

1. Select **uploading an existing file** or **Add file → Upload files**.
2. Upload the contents of this package, not the outer package folder.
3. Confirm that `README.md`, `CITATION.cff`, `NOTICE.md` and `REPOSITORY_SETUP.md` appear at the repository root.
4. Confirm that the PDF remains inside the `thesis` folder.
5. Use the commit message: `Publish public edition of master's thesis`.
6. Commit directly to the `main` branch.

## Post-publication checks

- The README renders on the repository landing page.
- The Mermaid diagram renders correctly.
- The PDF link opens from the README.
- GitHub displays **Cite this repository** from `CITATION.cff`.
- No email address, phone number or private document is exposed.
